# Modelos GLB opcionales

El visor 3D genera por código el modelo y el pelaje de cada animal.
Si quieres usar un modelo descargado (por ejemplo de Sketchfab o Poly Pizza
con licencia que permita usarlo), guárdalo aquí con el nombre del animal:

    leon.glb
    tigre.glb
    jaguar.glb
    leopardo.glb
    puma.glb
    jirafa.glb

El sitio lo detecta solo y lo carga en lugar del modelo generado. Si el archivo
trae animaciones llamadas "idle" o "walk" se usan con los botones Reposo y Caminar.

Revisa la licencia de cada modelo y da el crédito al autor en el README del proyecto.
